### What was learned
- SBCL `FORMAT` strings interpret `~` as a format directive — `~/.hngh/` in a FORMAT control string must be escaped as `~~/.hngh/` or the string breaks compilation. Only affects FORMAT control strings, not docstrings.
- Makefile phony targets can't share names with directory targets — `build` as both a phony target and the build directory caused a circular dependency. Fixed by renaming build dir to `bin/`.
- The `hngh:main` symbol must be exported from the `hngh` package for `save-lisp-and-die :toplevel` to find it.
- SBCL standalone binary is ~37MB for the current minimal skeleton (no external deps). Expected to grow as components are added.

#### What was learned
- SBCL `--no-sysinit --no-userinit` doesn't load contrib modules (sb-posix) — use `sb-ext:run-program` or add `(require :sb-posix)` in the Makefile's SBCL invocation
- `&key (var nil var-p)` — when the caller passes `:var nil`, `var-p` is T (the keyword was supplied). This means nil is a valid, intentional value, not "not supplied". Must check `var-p` before using `var` in a cond.
- `use-package` causes name conflicts when the package already has symbols with the same names as the source package's exports. Prefer qualified symbol references in test files.
- `uiop:delete-directory-tree` requires a `:validate` predicate for safety — `:validate #'identity` is the common pattern.
