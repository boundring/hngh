## Lessons

1. **The first live wrapped delegation is proven end-to-end within the
   existing bridge surface — and the fresh per-run store is
   load-bearing.** Session evening-beat4-docscheck-20260831 ran
   register → run-start → orient → work → run-end → present entirely
   on scripts/omp-bridge's real commands. A fresh per-run store
   (hngh-automation/bridge/20260831T1846Z-evening-beat4/) was required
   because omp-bridge hardcodes the run id `run-1`; a reused store
   would collide with any prior run-1. Probing an illegal `evacuated`
   close on the already-cancelled run was refused (invalid-transition)
   — the kernel refusing illegal transitions is the contract working,
   not a defect.
   Sources: docs/project/agent-handoffs.md:104 (--register);
   hngh-automation/bridge/20260831T1846Z-evening-beat4/; docs/project/reports.md:502-504
   (run-start/work/run-end progress rows); scripts/omp-bridge
   (run-id hardcode, close dispositions).

2. **Evidence over brief: check runtime-created files before declaring
   missing-reference defects.** Two premise corrections landed this
   wave from full source reads. (a) scripts/generate-publication
   consumes no docs/research/ lines and no research-lines manifest:
   `--ebook` reads a hard-coded 7-file list (script lines 235-247) and
   `--site` is a shell over scripts/dashboard-readout (timeline.md +
   queue.md + live store rosters) —
   docs/research/2026-08-30-publication-pipeline-grounding.md (213
   lines, 15/15 grounding paths verified). (b) A missing-file finding
   against docs/project/notify-log.md was closed as a false positive:
   the file is runtime-created by scripts/notify-agent append_hits,
   which creates it with the header on first hit (script lines
   115-132). A brief's premise is not evidence; the source is.

3. **Alert→plan-candidate routing threads resolved with selector
   evidence, and the resolution constrains the design.** Thread 1:
   candidates stage as docs/project/plans/*.plan.md —
   overnight-cycle.sh:186-199's selector greps exactly that surface;
   a queue-ledger column was rejected because queue.md is a fixed
   4-field TSV by contract. Thread 2: the dedup window is wall-clock
   only, so the minimal alert→step coupling is an identity naming the
   plan step with `--window 0`; re-arm after step close is parked with
   a router-side pre-check recommended.
   Source: docs/research/2026-08-30-alert-to-work-routing-patterns-closing-the-self-observation-loop.md,
   "Open-thread resolutions (2026-08-31)" (+86 lines).

4. **Parallel batched research beats is the delegation-lane conclusion
   applied live.** Four grounded docs (handoff-brief schema,
   steer-vs-die threshold, routing open-threads, publication
   grounding) landed in one parallel wave, while the grow beats
   (config-lanes, bridge delegation) serialized — research lanes are
   read-only-parallel, mutation lanes sequential. The steer-vs-die doc
   grounds its 5 signals in agent-watchdog.sh tunables
   (LOOP_N=3/ERROR_GRACE_MIN=2/STALL_MIN=10) and real reports.md rows
   (loop-signal/agent-stall/slow-unit/tree-skew); the handoff-brief
   schema anchors every field to its producer (active-work.md lane
   lines, agent-handoffs.md watchdog rows, omp-bridge --orient/
   --run-start brief) and frames thin fields as "not established".
   Sources: the four research docs listed above;
   docs/research/2026-08-30-delegation-lane-parallelism-multi-lane-omp-bridge-sessions-and-queueing.md
   (the conclusion being applied).
