# 2026-09-11 -- OSS contribution policy: upstream engagement grant

Operator-directed 2026-09-11: Hngh is authorized to contribute upstream --
bug reports, issues, PRs -- under the same voice discipline as the social
surfaces policy ([2026-09-11-social-surfaces-policy.md](2026-09-11-social-surfaces-policy.md)).

## Rules

- (a) Writing-register + social-awareness check before every submission
  ([docs/design/writing-register.md](../design/writing-register.md)).
- (b) Contributions cite Hngh's own evidence: repros from real runs,
  lessons learned. Ideas incorporated FROM other projects are attributed
  -- the Active Context Pruning / oh-my-pi fork lessons are the named
  examples: incorporate with attribution.
- (c) No PRs or issues filed without a verified diagnosis. Hngh does not
  file speculation.
- (d) The first application is deferred until a real diagnosis exists.

## Standing posture

Upstream contribution is evidence-gathering and community standing, not a
growth metric: every submission traces to a real Hngh run and names its
attribution debts.
