# Agent Platoons — 2026-08-02

## Projection

Today's bounded objective was to turn the existing `mc` and `agent-call`
primitives into a declarative, attended multi-agent squad launcher. The first
dogfood squad was a local-only OpenCode + Hermes AGENTS.md review. Remote model
quota was deliberately excluded because K3 and Copilot capacity are scarce.

Planned deliverables:

- Platoon design covering specs, roles, preflight, model routing, and journals.
- A launcher that reads a squad spec, starts attended tmux panes, injects wake
  prompts, and writes a projected journal.
- Role templates with the ponytail minimal-diff rules and shared-memory wake
  protocol.
- A projected/actual journal pair from the first dogfood run.
- Shared `avoid-ai-writing` skill installation for Hermes and OpenCode.

## Actual

- Design: `docs/design/agent-platoons.md` created.
- Launcher: `~/.local/bin/squad` passes Bash syntax and ShellCheck; parser,
  preflight, tmux launch, local-model routing, prompt injection, and journal
  creation were exercised.
- Dogfood: `duo-review` started as `squad-duo-review` with two local Gemma 4
  12B panes. Both agents reached ready state; Hermes completed the review.
- Journals:
  - Projected: `journal/squads/duo-review-20260802T142741Z-projected.md`
  - Actual: `journal/squads/duo-review-20260802T142741Z-actual.md`
- Prompt templates: seven role/base templates exist under
  `squads/templates/`; the two dogfood templates are standalone so v0 does
  not depend on inheritance support.
- Writing skill: installed at `~/.hermes/skills/writing/avoid-ai-writing/` and
  `~/.config/opencode/skills/avoid-ai-writing/`; hashes match.

## Deviations And Lessons

- The first parser version had unbalanced Lisp forms and emitted journal
  entries inside the member loop. The parser was fixed before the successful
  launch.
- OpenCode's TUI needed a settling delay; a false readiness match caused the
  first coordinator prompt to be dropped. The launcher now waits for actual
  TUI markers and settles before injection. The current run required one
  manual concise wake because it started before that fix.
- Unsloth is reachable at `:8888` but returns HTTP 401 without credentials;
  the launcher records reachability and does not claim model identity.
- `mcp-list` is absent, so MCP declarations are recorded as warnings rather
  than probed by an invented protocol.
