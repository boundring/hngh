## TASK — plugin spec

`src/plugins/emacs-daemon.lisp`, package `:hngh.plugins.emacs-daemon`:

- `(daemon-alive-p)` — T when `emacsclient --eval t` exits 0 within ~5s
  (run-program :wait t).
- `(start-daemon &key (load-files nil))` — spawn `emacs --daemon` (plus
  `--load file` per load-file), then poll daemon-alive-p up to ~15s, 1s
  interval. Return T/NIL. Never error if a daemon already exists (idempotent:
  alive → log + T).
- `(stop-daemon)` — `emacsclient --eval "(kill-emacs)"` only when
  daemon-alive-p; NIL otherwise. Never touches non-daemon GUI emacs (kill-emacs
  via emacsclient only reaches the daemon server).
- `(health)` — plist `:alive :pid` (pid from
  `emacsclient --eval "(emacs-pid)"`, parsed, NIL on any failure).
- `init` — log-info state; does NOT auto-start the daemon (policy: start is
  an explicit user/other-plugin action).
- `shutdown` — plugin bookkeeping only; MUST NOT stop the emacs daemon (the
  daemon outlives hngh, like the tmux session outlives mission-control).
- `running-p`, `status` (plist: :running :daemon-alive :pid).

Wire into packages.lisp (exports: init shutdown running-p status
daemon-alive-p start-daemon stop-daemon health), hngh.asd, main.lisp per the
mirror notes above.
