# Pre-consolidation archive

This directory holds the historical Hngh project material moved during the 2026-08-10 documentation reorientation.

## Contract

- Legacy content was moved without textual edits.
- Git history and the consolidation manifest provide recovery.
- Archive material is evidence and reference, not current execution authority.
- Compatibility symlinks preserve old documented/programmatic paths; they are not the working documentation surface.
- Runtime/workbench state is excluded. It has a distinct retention and rollback boundary.
