# Hngh

> Hngh Network. Goes Hngh.

Hngh is a local-first system harness for CachyOS/Arch Linux. It coordinates existing agentic tools, local and remote model routes, and Linux automation with explicit authority, evidence, cost, and recovery boundaries.

It is built first for the operator's own environment. The resulting controls, case base, and redacted evidence support a future consultation practice for people who need agentic solutions fitted to their own systems.

## What Hngh owns

- task admission, claims, capability gates, and operator decisions;
- session lifecycle, compact handoff, retirement, and afterlife reduction;
- model-route, quota, context, and receipt control;
- durable records, review evidence, backup/sync integration, and operator visibility.

Hngh does not replace Hermes, OpenCode, ACP/MCP tools, local inference runtimes, or provider APIs. It treats them as bounded adapters. The AI never runs as root.
