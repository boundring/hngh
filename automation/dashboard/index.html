Operator console over the automation spine — queue, agents, rotation, logs. Governance stays certificate-gated; this page never feeds a gate.

Glossary — what the terms mean
hngh
the self-governed run/commit engine whose work this collection tracks.
run
one bounded execution (create → admit → review → close).
agent
a live worker attached to the collection.
evacuated
an agent/run parked or shelved — not failed.
rotation
a timed state checkpoint (day marker on the schedule axis).
lane
an ordering slot in the backlog; each lane depends on the lane ahead of it — no fixed date.
spine
the JSON feed (verdict + timeline + queue + lanes + roster) behind the header strip.
beacon
the pulse dot in the strip: green = fresh data, amber = stale, red = unreachable.
run id
session ids look like run-20260827T200145Z-2672106: run-<UTC timestamp>-<pid> of the wake that spawned the agent.
loadout
the model plus time/budget limits a worker is admitted with for one run.
certificate-gated
a change only commits when a certificate binds it to operator-verified evidence.
tier
cadence bucket of a recurring job: 1m / 5m / 10m / hour / day / quarter.
drop-in
a one-off lane inserted between recurring lanes in the rotation ("cadence drop-in" source).
record.lisp / receipt tail
per-run store file and the last lines of its log; dashboards read only the tail.
gbd-lane
git-back-dots — the operator-run config-parity lane; no fixed cadence.
grow / research beat
the recurring exploration/learning slot in the rotation (Research tab).
ledger p50
median wall time of a unit's past runs — the preferred duration estimate for lanes.
Camp
the landing view (canonical term: overview) — verdict with its reasons, open operator items, attention crumbs, today's dispatch excerpt.
winamp
the dashboard's one fixed theme; there is no theme button.
KB
the knowledge-base tab: snapshots of the wiki's source pages.
OMP
oh-my-pi — the agent harness whose sessions appear in the roster.
steer
a mid-run course-correction message sent to a live agent; shows up in Reports.
