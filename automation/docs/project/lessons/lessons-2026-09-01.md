# Lessons harvested 2026-09-01

## Lesson 1: Session cost telemetry has not yet emitted rows

`jobs/session-cost.py` spec says it emits one row per finished omp session
with `kind=session-cost`. The telemetry store (`dashboard/telemetry.db`)
has no such rows yet. The script imports `sessions-feed.py` and uses
`omp_candidates` discovery; it likely needs the sessions-feed to have
run first to populate the discovery window.

**Rule:** session-cost rows require a preceding sessions-feed run. Add a
comment to `jobs/session-cost.py` noting this dependency.

**Source:** `logs/budget.md` last row 2026-09-02T00:35:09Z; email-digest
output "no session-cost rows yet".

## Lesson 2: publish pipeline script does not exist

`scripts/generate-publication` does not exist in the automation repo.
The operator's directive references it as consuming `docs/research/` lines
via a hard-coded 7-file list. Without the script, the ebook-longform and
ebook-book-inputs backlog rows cannot be unblocked.

**Rule:** the generate-publication script is a critical dependency for the
self-funding pipeline. The operator needs to author it or delegate it as a
separate grow beat.

**Source:** `docs/project/backlog.md` ebook-longform row;
`docs/research/2026-08-30-publication-pipeline-grounding.md` 15/15
grounding paths verified but no script on disk.

## Lesson 3: SMTP config missing blocks email channel

`~/.hngh-automation/notify-email.conf` does not exist. The notify-email.py
script exits 2 with "no config at ...". The email channel is dormant.
This is an operator setup item — the operator must place the INI file.

**Rule:** the email channel requires operator action (placing the config
file). The machine cannot complete this step autonomously.

**Source:** `scripts/notify-email.py` exit-2 output; `ls ~/.hngh-automation/`
confirms no notify-email.conf.

## Lesson 4: research dir is empty except for two files

`docs/research/` only contains the two files written by this plan
execution: `2026-09-01-notification-channel-survey.md` and
`2026-09-01-roguelike-pattern-design.md`. The other research docs (session
cost model, benchmark loop, scheduling design) are missing — they need to
be written as separate research beats.

**Rule:** research docs should be batched into single beats to avoid
fragmentation. Each beat should cover 2-3 related topics.

**Source:** `ls docs/research/` shows only the two files.

## Lesson 5: records dir is empty

`docs/records/` is empty. The biographic capture row was the first file
written there. Records should be written as a growing ledger, not a single
file.

**Rule:** records are append-only. Each day's events get their own file.
The README format spec says "records preserve verified facts, decisions,
and bounded unknowns."

**Source:** `docs/records/README.md` format spec.

## Lesson 6: plans dir is empty

`docs/project/plans/` does not exist. The plans contract expects plan
files there. The overnight cycle reads from `docs/project/plans/` and
writes to `dashboard/plans.json`. Without the dir, plans cannot be stored.

**Rule:** the plans dir needs to exist for the plan acceptance gate to
work. The overnight cycle should create it if missing.

**Source:** `scripts/accept-plans.py` reads from `docs/project/plans/`;
`dashboard/plans.json` has entries but the source dir is missing.
