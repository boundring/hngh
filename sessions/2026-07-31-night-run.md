## GUARDRAILS (non-negotiable)

- Tasks are TEXT-IN → TEXT-OUT. The 12B returns content; NOTHING writes the
  repos overnight. Orchestrator applies good output in the morning.
- Each task: "produce the artifact as your full reply." Result lands in
  `queue.lisp` `:result`. Morning review reads `:result`, applies, tests.
- Driver is serial, one task per tick, `hngh --once` per tick (M3 semantics).
- Kill-switch: `touch ~/.hngh/tasks/STOP` → orchestrator's tick loop checks
  for it between `hngh --once` calls and stops.
- Max 6 tasks. No retries on `:failed` — a failed task is left for morning,
  the driver moves on (no infinite loop, no token bleed).
- Prompts must NOT over-restrict output length — the 12B reasons before
  answering (verified: needs room; `max_tokens:10` returned empty).
