`special-mode`. Read the whole file first and mirror its idioms.

The hngh task queue lives at `~/.hngh/tasks/queue.lisp`: a single Lisp list of
plists, one plist per task, keys `:id :task :status :policy :result :error
:submitted-at :finished-at`. Status values seen: `:done`, plus (per source)
`:pending :in-progress :failed`. `:submitted-at`/`:finished-at` are universal
times. `:task` is the full prompt string (long — truncate for display).
`:result` is a JSON string (chat completion) when done; `:error` holds failure
info. The file is read by hngh with `*read-eval*` NIL — treat it as untrusted:
in elisp, do NOT `read` it with `read` on arbitrary objects... actually elisp
`read` has no eval side effects from data alone, but DO wrap parsing in
`condition-case` and fail closed to an error notice in the panel, never crash
the timer tick.
